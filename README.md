# Meland - Plateforme de Gestion de Prêts (Côte d'Ivoire)

Meland est une solution web moderne conçue pour faciliter l'accès aux offres de financement en Côte d'Ivoire. La plateforme permet une mise en relation fluide entre les demandeurs de prêts et les structures financières partenaires.

## Fonctionnalités

### Pour les Utilisateurs
- **Recherche d'offres** : Filtrez les prêts par type (scolaire, agricole, PME, etc.) et par commune.
- **Consultation** : Visualisez les détails complets, les taux d'intérêt et les conditions d'éligibilité.
- **Demande simplifiée** : Boutons d'action pour contacter directement les structures.

### Pour les Structures Financières
- **Espace de gestion** : Tableau de bord pour suivre les statistiques de visibilité.
- **Gestion du catalogue** : Outils pour ajouter, modifier ou supprimer des offres de prêts.
- **Visibilité Premium** : Mise en avant des offres certifiées.

## Structure du Projet

Le projet est construit avec des technologies robustes :
- **Backend** : Java (Spring Boot) pour une sécurité et une performance optimales.
- **Interface** : Design moderne et réactif avec Tailwind CSS.
- **Organisation** : Architecture MVC propre pour une maintenance facilitée.

## Comment lancer l'application ?

1. Assurez-vous d'avoir Java (JDK 17+) et Maven installés.
2. Dans votre terminal, lancez la commande : `mvn spring-boot:run`
3. Ouvrez votre navigateur à l'adresse suivante : `http://localhost:8080`
